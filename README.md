# Calculator lab project

## Prerequisites
- Python 3 must be installed.

## How to run it
1. Open a terminal in the calculator folder.
2. Run the startup script:

   ./run.sh

## Sample test
Enter the following values:
- First number: 6
- Operator: *
- Second number: 7

Expected result:

Result: 42.0

## How to stop
Press Ctrl + C in the terminal.
